# PI Dominó Químico ETEC-Julio de Mesquita
## Terceiro semestre - IMT(Instituto Máua de Tecnologia)
- Este projeto consiste em um jogo educacional digital no formato de dominó, desenvolvido para auxiliar alunos do ensino médio na aprendizagem de funções inorgânicas (ácidos, bases, sais e óxidos). A proposta é permitir que os estudantes conectem peças com informações complementares — como fórmula, nome, função e propriedades — reforçando o reconhecimento e a classificação dos compostos químicos. O jogo busca tornar o aprendizado mais interativo e intuitivo, estimulando a associação lógica e reduzindo a dependência da memorização mecânica.
